# 奇门遁甲 · Windows 一键版

下载、解压，双击 **`一键启动-奇门遁甲.bat`**。首次自动下载基础模型并打开网页，以后直接本地启动。

![奇门遁甲首页](web/hero-youth-qimen.png)

## 使用方法

1. 点击本仓库 **Code → Download ZIP**，完整解压到一个可写目录。不要在压缩包内部直接双击。
2. 双击 **`一键启动-奇门遁甲.bat`**，保持启动窗口开启，等待首次准备完成。
3. 浏览器自动打开 [本机页面](http://127.0.0.1:8317/#/)，可以排盘、观看演局、查看九宫详情、六类问事及生成白话断语。
4. 使用结束后，双击 **`停止-奇门遁甲.bat`** 释放模型占用的内存和显存。只关闭浏览器不会停止模型服务。

## 首次启动

- 需要 **Windows 10/11 64 位**，无需安装 Python、Node.js 或开发工具。
- 基础模型约 **4.7 GB**，首次从 Qwen 官方 ModelScope 仓库下载，备用来源为 Hugging Face。下载中断后再次双击可续传；下载完成会校验 SHA256。
- 缺少微软 VC++ x64 运行库时，脚本会下载微软官方安装包，验证数字签名后请求安装。Windows 可能弹出权限确认。
- 建议至少 **16 GB 内存、8 GB 可用磁盘空间**。优先使用支持 Vulkan 的显卡；显卡启动失败时尝试 CPU，CPU 生成较慢。上述配置是建议值，未验证所有硬件的最低要求。
- 首次准备完成后，可在断网环境继续使用。网页不调用远程 AI 服务；问事和生成均在本机进行。

## 常见问题

- **下载失败**：检查网络后重新双击，已下载的 `.part` 文件会保留供续传。两个官方来源都不可达时，需要能够访问 ModelScope 或 Hugging Face 的网络。
- **提示 8317 端口被占用**：先关闭占用该端口的其他应用，脚本不会结束其他程序。已经启动本应用时再次双击，只会重新打开网页。
- **模型加载或生成失败**：查看 `.runtime` 目录中的服务日志。更新显卡驱动后重试；启动器会对显卡初始化失败尝试 CPU。
- **需要迁移到离线电脑**：在联网电脑成功启动一次并停止服务，然后复制整个解压目录，包含 `models` 与 `.runtime`。目标电脑需已有 VC++ x64 运行库；如果没有，请提前下载[微软安装包](https://aka.ms/vs/17/release/vc_redist.x64.exe)，命名为 `vc_redist.x64.exe` 放入 `.runtime`，启动器会验证并复用。
- **网页刷新**：页面使用 `/#/paipan`、`/#/wenshi` 等地址；保留 `#` 后的路径即可。

## 包内内容

| 路径 | 用途 |
|---|---|
| `一键启动-奇门遁甲.bat` | 自动准备与启动 |
| `停止-奇门遁甲.bat` | 停止本应用的模型服务 |
| `web/` | 已构建的完整网页、图片和排盘逻辑 |
| `runtime/llama-vulkan.zip` | 固定版本的 Windows x64 推理程序，支持 Vulkan/CPU |
| `runtime/manifest.json` | 模型来源、版本与校验值 |
| `models/duanyu-lora-f16.gguf` | 项目断语适配模型 |
| `licenses/` | 上游程序及基础模型的许可说明 |

基础模型由首次启动下载，不进入 Git。运行产生的缓存和日志也不进入 Git。本仓库仅包含运行成品。
